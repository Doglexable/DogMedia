    DOGMEDIA / THE IDEA

    Koleksimu tetap
    di tempatmu.

    Musik, video, dan foto dalam satu ruang yang kamu kelola sendiri. Halaman ini hanya memperlihatkan pengalaman mendengar; player demo tidak terhubung ke library privat.

    © 2026 Dogmedia — Ruang privat untuk mediamu.
    TRANSPARANSI DATA · PRIVATE-FIRST ARCHITECTURE

    Transparansi Data Aplikasi

    Baik dioperasikan sebagai layanan publik maupun media server mandiri, berikut rincian terbuka seluruh data yang diproses aplikasi agar dapat berfungsi.

    🌐

    Halaman Demo Interaktif

    Halaman demo ini berjalan terisolasi di sisi peramban dan tidak mengambil data sensitif maupun riwayat pustaka privat.

    Audio Demo 0 Byte dari server media. Seluruh nada dan instrumen disintesis langsung di peramban via Web Audio API lokal.
    Cookies & Pelacak Nol (0) Cookie. Tidak ada cookie pelacakan, tidak ada Google Analytics, Pixel, atau SDK eksternal.
    Content Security Header CSP connect-src 'none' secara ketat memblokir koneksi jaringan keluar dari browser pada halaman demo.
    👤

    Akun Pengguna & Kredensial

    Data identitas akun yang digunakan untuk autentikasi dan pengaturan hak akses pengguna pada layanan ini.

    Nama Pengguna Username unik untuk login dan identifikasi profil akun pada aplikasi.
    Kata Sandi Hanya disimpan dalam bentuk hash Argon2. Kata sandi teks asli tidak pernah disimpan, tidak dicatat dalam log, dan tidak dapat dilihat oleh siapa pun.
    Tingkat Izin (Tier) Penanda peran (misal Tier 0 untuk pengguna standar, Tier 100+ untuk pengelola) untuk menentukan pustaka media yang dapat diakses.
    Foto Profil Berkas avatar gambar opsional yang diunggah pengguna untuk tampilan akun (dapat diubah atau dihapus kapan saja).
    📊

    Riwayat Pemutaran & Sesi Login

    Semua data aktivitas pemutaran terikat langsung ke akun pengguna (User ID), bukan ke alamat IP perangkat.

    Token Sesi Token acak terenkripsi bertempo kedaluwarsa otomatis (TTL) dalam cookie HTTP-only aman untuk menjaga status login Anda.
    Rekap Statistik Mencatat ID media, waktu putar, dan durasi mendengarkan untuk menghasilkan rekap statistik pemutaran personal (*Wrapped*).
    Resume Position Menyimpan posisi menit/detik terakhir saat jeda secara sementara di memori (TTL 15 menit) agar lagu/film bisa dilanjutkan di titik jeda.
    Koleksi & Antrean Menyimpan daftar lagu yang disukai (Liked Music) dan daftar antrean putar (Queue) aktif per akun.
    Playback Sync Status perangkat aktif untuk sinkronisasi pemutar antar browser, aplikasi desktop, maupun mobile.
    📁

    Penyimpanan Media & Konten Berkas

    Konten audio, video, dan gambar yang diunggah serta dikelola pada penyimpanan instans aplikasi ini.

    Penyimpanan Media File mentah audio, video, dan foto disimpan di volume penyimpanan instans ini, bukan di cloud publik pihak ketiga.
    Metadata Media Judul, nama artis, nomor urut track, cover art, format MIME, serta berkas lirik (.lrc) dan takarir subtitle (.vtt/.srt).
    Varian Streaming Hasil transcode resolusi adaptif (720p, 1080p, audio stream) yang diproses otomatis untuk kelancaran streaming.
    Tautan Berbagi Token acak publik yang dibuat hanya jika pengguna memilih membagikan lagu atau reels dengan batas waktu kedaluwarsa.
    🛡️

    Alamat IP, Jaringan & Keamanan

    Data koneksi jaringan diproses murni untuk proteksi teknis, integritas server, dan pencegahan penyalahgunaan.

    Rate Limiting Alamat IP klien hanya dibaca secara sementara di memori server untuk mencegah serangan brute-force login, spam request, atau DoS.
    Log Web Server Log akses standar server (IP, User-Agent, status respons) untuk mendiagnosis kendala koneksi dan lalu lintas teknis.
    Tanpa Pelacak Pihak Ketiga Tidak ada data pengguna yang dijual, ditautkan ke profil periklanan, atau dialirkan ke penyedia pelacak pihak ketiga.
    🔒 Privasi terproteksi · Tidak ada penjualan data atau integrasi pihak ketiga.
