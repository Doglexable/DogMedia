## Findings considered and rejected

- *Migrate entire monorepo to TypeScript*: Rejected — JS ESM is intentional by design per AGENTS.md; JSDoc / `checkJs` via `jsconfig.json` is preferred and lower risk without breaking build pipelines.
- *Replace IP-based authorization with user login accounts*: Rejected — IP-based whitelist is the core architectural principle of DogMedia.
- *Remove Redis or SQLite*: Rejected — Redis (queues, active sessions) and SQLite (mobile offline) are settled architectural decisions.
- *Complete architectural rewrite of GlobalPlayer*: Rejected — High risk for core audio/video streaming engine; incremental hook extraction is preferred once playback characterization tests are in place.
